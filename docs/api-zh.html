马来西亚 API：计算方法、滞后与学校烟霾监测

与新加坡、美国、中国和香港的比较，以及 Sasana 烟霾监测网站的实践

一位家长（AI 辅助） · 2026 年 10 月 18 日

摘要

马来西亚的 API 看的是过去 24 小时的平均空气，不是此刻的空气。所以烟霾来时，API 升得慢；烟霾走后，API 降得也慢。本文说明 API 的计算方法，用学校附近四个监测站的每小时数据说明这种滞后，与新加坡、美国、中国和香港比较，讨论取得较即时 PM2.5 数据的两个途径，最后介绍本网站的监测工作。

关键词：空气污染指数；PM2.5；滚动平均；滞后；烟霾；学校监测

本文为个人整理，仅供参考。作者以家长个人身份撰写，不代表学校立场，也不构成健康建议。

1 引言

很多家长有过这样的经历：窗外很灰，闻到烟味，但 API 还显示“中等”。打开外国的空气 App，同一时间却显示“不健康”。哪个数字是对的？

两个数字都可能没有错。它们只是在回答不同的问题。本文用简单的话说明四件事：

  • API 是怎样算出来的；
  • 为什么 24 小时平均会“慢半拍”；
  • 新加坡、美国、中国和香港怎样处理同一个问题；
  • 本网站在做什么，目的是什么。

2 API 是什么

API 是“空气污染指数”（Air Pollutant Index），由马来西亚环境局（DOE）公布。它把空气里的污染物换算成一个没有单位的数字。数字越大，空气越差。

表 1　API 等级与环境局的健康建议

API 状态 环境局的健康建议（简化）
0–50 良好 户外活动不受限制
51–100 中等 户外活动不受限制
101–200 不健康 老人、孕妇、儿童和心肺病患者减少户外活动
201–300 非常不健康 高风险人群留在室内
301 以上 危险 公众避免户外活动

环境局在全国有 68 个监测站，每小时更新一次 API。官方的查看渠道是 APIMS 网站和 MyJAS EQMS 手机 App。

3 API 怎样计算

API 等于六种污染物“分指数”中最高的一个。环境局的官方计算文件分三步说明[1]：

  1. 测量六种污染物。 它们是 PM2.5、PM10、臭氧、一氧化碳、二氧化氮和二氧化硫。
  2. 按各自的时间求平均。 每种污染物的平均时间不同，因为人体能承受的接触时间不同。
  3. 换算成分指数，再取最高值。 每个平均浓度用一条公式换算成 0 至 500 的分指数。最高的分指数就是该站的 API。

表 2　各污染物的平均时间

污染物 平均时间
PM2.5（细悬浮微粒） 24 小时
PM10（可吸入悬浮微粒） 24 小时
臭氧 8 小时，也看 1 小时
一氧化碳 8 小时
二氧化氮 1 小时
二氧化硫 1 小时

举例：某站 PM2.5 的分指数是 152，臭氧是 40，其他更低。那么该站 API 就是 152，主要污染物是 PM2.5。

环境局的文件也说明，在马来西亚，API 大多数时候由微粒决定，烟霾期间尤其如此。PM2.5 从 2017 年起列入计算（文件的写法），新闻多以 2018 年 8 月为对外公布的开始。换算公式见附录 A。

4 公布了什么，没有公布什么

环境局公布每站每小时的 API 和主要污染物，也公布了换算公式；但公众看不到每小时的 PM2.5 浓度。

  • 公布了： 每小时的 API 数字、状态和主要污染物。
  • 公布了： PM2.5 等污染物换算成 API 的公式。环境局网站上有官方的《API 计算》文件，用马来文和英文写成。
  • 没有公布： 每小时的 PM2.5 浓度（单位：微克/立方米）。马来亚大学的 Helena Varkkey 副教授指出，政府手上有每小时数据，只是没有对外公布[4]。

所以，一般公众只能看到 24 小时平均后的 API。看不到“这一个小时”的空气有多差。

一个需要注意的地方： 环境局有两份官方《API 计算》文件：2021 年 9 月版本（环境局网站）和 2025 年 1 月版本（APIMS 网站）。两者的 PM2.5 换算数字不一样[1, 2]（见附录 A）。本文以较新的 2025 年 1 月版本为准。这不影响本文的主要结论：24 小时平均会带来滞后。

5 为什么 24 小时平均会“慢半拍”

24 小时滚动平均每小时只换掉二十四分之一的数据。所以烟霾来了，要约一天才完全反映；烟霾走了，也要约一天才消失。

  • 每过一小时，平均值加入最新的一小时，去掉 24 小时前的一小时。
  • 最新的一小时只占平均值的二十四分之一。
  • 所以 API 的高峰比实际高峰来得晚，也比实际高峰低。一项用曼谷数据的研究发现，这种平均比每小时数据晚约 10 至 13 小时[11]。

烟霾到达后，美国的 NowCast 几小时内就升高。24 小时平均却要到烟霾散去时才升到最高，之后又要一整天才降回来。

5.1 学校监测数据中的例子

  • 10 月 17 日下午 2 时，四站平均 API 是 150。这个数字代表 16 日下午 3 时至 17 日下午 2 时的空气，不只是 17 日下午的空气。
  • 到 18 日早上 10 时，平均还有 139，只比前一天下午低 11 点。空气即使已经好转，数字也是慢慢下降。
  • 例外： 按 2025 年 1 月版本的换算表，API 101 至 150 只对应约 5 微克/立方米的浓度差。所以 API 在这一段可以变得很快。例如 10 月 16 日下午 4 时至晚上 8 时，瓜拉雪兰莪站从 152 降到 99。在 150 附近，很小的浓度变化就足以使 API 跨过这个数值。

5.2 四个站的每小时数据

下图是 10 月 8 日晚上至 18 日上午 11 时，四个站全部的每小时 API[12]。浅蓝色带标出 API 100 至 150 这一段。

  • 单一站点穿过 100–150 很快。 通常只要几个小时，例如 10 至 11 日的下降、13 至 14 日的上升，以及 16 日傍晚瓜拉雪兰莪站的急降。这符合这一段很陡的特点。
  • 四站平均却会在 100–150 停留较久。 例如 17 日至今：三个吉隆坡和雪兰莪的站在 150 以上，瓜拉雪兰莪站在 100 以下，平均刚好落在中间。
  • 所以，平均落在 100–150，不一定表示某个站在这一段。 更常见的情况是站与站之间差距很大。
  • 瓜拉雪兰莪站常常不同。 它靠海，常比其他三站低，升降也更急。这可能与海风有关，但还没有用风向数据验证。

6 其他地方怎样做

新加坡、美国、中国和香港也用 24 小时或较长的平均来评估健康风险，但都另外给公众一个“较即时”的数字。马来西亚是这五个地方中唯一只给一个 24 小时数字的。

表 3　五地空气质量指数的比较

地方 主要指数 主要指数的平均时间 较即时的数字 政府建议的用法
马来西亚 API PM2.5：24 小时滚动平均 没有 只看 API
新加坡[6] PSI 24 小时 1 小时 PM2.5 浓度，分四级（正常、偏高、高、非常高），2016 年起分级 马上要做的活动看 1 小时 PM2.5；计划明天的活动看 24 小时 PSI 预报

几个重点：

  • 新加坡的做法和马来西亚最接近，但多了一个 1 小时 PM2.5。新马两地常被拿来比较，其实比较时要先看清楚是 1 小时还是 24 小时的数字。
  • 美国的 NowCast 是一个折中：在空气稳定时像 12 小时平均，在空气变化快时像 3 小时平均。美国环境保护局的例子是：一小时的高峰过后，NowCast 每过一小时减半；同一天的 24 小时平均只剩高峰的二十四分之一。
  • 香港在 2013 年底改用 AQHI，直接用 3 小时平均，所以反应最快。

马来西亚学者 Varkkey 和 Ashfold 在 2023 年建议：公布每小时 PM2.5 不需要新的设备，只是把已有的数据公开[4]。

7 讨论

  • 两种数字回答不同的问题。 24 小时平均反映过去一整天的累积接触，适合与以 24 小时为单位的健康标准比较；每小时数字反映当下的空气。
  • 两者的差别在空气快速变化时最明显。 烟霾刚到达时，24 小时平均偏低；烟霾刚散去时，24 小时平均偏高（见图 1）。空气稳定时，两者接近。
  • 其他地方的官方做法。 新加坡国家环境局的说法是：即时活动参考 1 小时 PM2.5，次日计划参考 24 小时 PSI 预报。美国的官方地图以 NowCast 显示“现在”的数字。
  • 学者的看法。 双威大学的 Fatimah Ahamad 博士在接受 SAYS 访问时表示，较长的平均时间能反映累积的健康风险，但在烟霾突然加重时，可能掩盖正在形成的烟霾[4]。
  • 外国 App 的数字与 API 不能直接比较。 环境局在 2026 年 10 月说明，两者的标准、平均时间和更新时间都不同[5]。
  • 换算表各段的敏感度不同。 按 2025 年 1 月版本，API 101–150 这一段很陡：PM2.5 只要变化约 5 微克/立方米，API 就会在 100 和 150 之间移动。上升和下降都一样，所以在这一段，小变化看起来像大变化。API 151–200 这一段则很平：PM2.5 从 60 升到 110，几乎翻倍，API 只从约 153 升到 179，所以严重烟霾时的变化看起来较小。例如 10 月 16 日傍晚，瓜拉雪兰莪站 4 小时内从 152 降到 99，按换算表反推，PM2.5 只从约 57 降到约 50。
  • 与旧版本相比，新版本较早触发界线。 在 PM2.5 约 50 至 150 微克/立方米之间，2025 年 1 月版本算出的 API 都比 2021 年 9 月版本高。按新版本，学校的 150 界线相当于 PM2.5 24 小时平均约 55 微克/立方米，180 界线约 112 微克/立方米；按旧版本则分别约 113 和 135。
  • 与健康标准的对照。 世界卫生组织没有类似 API 的指数，而是订出 PM2.5 浓度的指引值：24 小时平均 15 微克/立方米，年平均 5 微克/立方米，另有四级过渡目标[13]。马来西亚 2020 年的环境空气质量标准是 24 小时平均 35 微克/立方米[14]。按 2025 年 1 月版本，API 100（“中等”的上限）相当于 50.4 微克/立方米，高于马来西亚本身的 2020 年标准，也高于世界卫生组织的指引值（表 4）。

8 实时 PM2.5 从哪里来

8.1 只看 API 的挑战

前面几节说明，公众若只看 API，要判断“此刻”的空气会遇到三个挑战。

  • 滞后。 API 是 24 小时平均，比每小时数据晚约 10 至 13 小时。烟霾到达时，API 升得慢；烟霾散去后，API 降得也慢（第 5 节）。
  • 没有每小时 PM2.5。 环境局只公布 API，不公布每小时 PM2.5 浓度（第 4 节）。公众因此无法自行计算较即时的指数，例如美国的 NowCast。
  • 换算表的敏感度不均。 在 API 101–150 这一段，PM2.5 的小变化使 API 大幅变动；在 151–200 这一段，PM2.5 的大变化只使 API 小幅变动（第 7 节）。只看 API 的升降，难以判断浓度实际变化了多少。

要看到较即时的空气情况，需要 API 以外的数据来源。以下讨论两个途径。

8.2 附近的低成本传感器

  • 本网站从 2026 年 10 月 18 日起，每小时收集一个低成本传感器的读数。它位于 Rawang Anggun（Jalan Anggun 3P），距离学校约 2.7 公里；最近的环境局监测站在 19 公里外。
  • 传感器型号是 GAIA A08，内有一个 Plantower PMS5003 激光颗粒计数器，数据经 aqicn.org 公开[10]。
  • 本网站把它的读数与四个环境局监测站比较，结果见传感器比较页面。目前数据太少，还不能下结论。
  • 这个来源有几个限制：
    • 传感器属于私人，可能随时离线或搬走。
    • aqicn 提供的是美国 AQI 指数，不是浓度，需要换算。
    • 低成本传感器在湿度高时，读数往往偏高，需要用环境局的数据校准。
    • 只有一个计数器，出现故障时不容易发现。

8.3 在学校设置传感器

学校也可以考虑在校园内设置自己的传感器。这样量到的就是学校本身的空气，数据也由学校掌握。

  • 两个传感器比一个可靠：一个故障时，另一个仍能工作；两者读数不一致时，也能及早发现问题。
  • 新传感器宜先运行一至两周，与环境局的 24 小时平均比较，得出校正系数。
  • 本网站的做法是：传感器数据只作参考，学校规则只使用环境局的官方 API。

9 本网站的监测工作

本网站（Sasana 烟霾监测）由一位家长建立，2026 年 10 月起运行，不是学校的官方公告。网站做三件事：按学校现行规则监测、预报和传感器比较。

9.1 按学校现行规则的监测

  • 学校的烟霾规则以四个环境局监测站下午 2 时的 API 平均为准：巴都慕达（19 公里）、八打灵再也（22 公里）、莎阿南（24 公里）和瓜拉雪兰莪（33 公里）。
  • 平均超过 180，次日停课；连续三天超过 150，次日停课；停课期间，平均低于 150，次日复课。
  • 网站每小时自动收集四个站的 API，在每天下午 2 时后按规则算出次日的状态。读数迟到时，网站在 15 分钟后再收集一次。
  • 所有每小时读数和每日结果都公开存档（从 2026 年 10 月 3 日起），可供核对。
  • 目的：按同一套规则，在学校公布前显示可能的结果，并公开计算过程。
  • 网站对规则有两处解读：平均值先四舍五入成整数；恰好 150 和 180 算作超标。学校通告的原文是“超过”。10 月 17 日的平均恰好是 150，两种读法的结果不同。

9.2 预报

  • 网站每天两次（上午和晚上 7 时 30 分），用欧洲哥白尼大气监测服务（CAMS）的 PM2.5 预报，估算未来五天下午 2 时的四站平均 API。
  • CAMS 是全球模型，网格约 40 公里，在烟霾时常低估浓度。网站用监测站的实际读数校正：比较由 API 反推的 PM2.5 与 CAMS 的数值，得出校正系数，并参考最新的实际读数。
  • 目的：为未来几天提供计划上的参考。预报从不用于判断开课或停课。
  • 预报可能有很大误差。10 月 17 日早上的预报是 85，实际是 150；之后网站修改了方法。每次预报都有存档，日后可以检验准确度。

9.3 传感器监测

  • 网站从 10 月 18 日起记录 Rawang Anggun 的低成本传感器（见 8.2）。它距离学校约 2.7 公里，比最近的环境局监测站近得多。
  • 网站把它的 PM2.5 读数按 2025 年 1 月版本的换算表换成“API 等值”，并计算 1、3、6 和 24 小时平均。
  • 目的一：提供较即时的参考，弥补 API 的滞后（见 8.1）。
  • 目的二：为瓜拉雪兰莪站的问题提供依据（见 9.4）。
  • 传感器数据只作参考，不用于学校规则。

9.4 是否纳入瓜拉雪兰莪站

  • 校内对学校规则是否应纳入瓜拉雪兰莪站，曾有不同意见。
  • 该站与其他三个站不同：距离最远，位于西面沿海；其他三个站在吉隆坡和八打灵再也一带，彼此接近。烟霾时，它的读数常明显较低（图 2）。
  • 这个选择会改变结果（表 6）。10 月 9 日至 18 日的 10 天中，有 3 天（10、14 和 18 日）一种平均达到 150，另一种没有。
  • 按三站平均，连续三天的条件在 10 月 16 日已满足，10 月 19 日（星期一）仍会停课。按四站平均，条件在 10 月 17 日才满足，10 月 19 日复课。

10 本文的局限

  • 数据只涵盖 2026 年 10 月 8 日至 18 日，约 10 天，四个监测站。
  • 环境局只公布 API，没有公布每小时 PM2.5 浓度。本文提到的浓度，都是按换算表从 API 反推的。
  • 新换算表从哪一天开始用于计算 API，环境局没有说明。本文的数据检验显示，10 月 10 日至 18 日的读数都符合 2025 年 1 月版本，而不符合 2021 年 9 月版本。这份文件至少从 2026 年 6 月起已在网上，内容没有改变。
  • 瓜拉雪兰莪站与海风的关系只是推测，未用风向数据验证。
  • 作者不是空气质量专业人士。文中如有错误，请以环境局的资料为准。

11 结论

  • API 是六种污染物分指数中的最高值；烟霾时通常由 PM2.5 决定。
  • PM2.5 用 24 小时滚动平均，所以 API 比实际空气慢大约半天，峰值被压低。
  • 环境局公布了换算公式，但没有公布每小时的 PM2.5 浓度。
  • 新加坡、美国、中国和香港都另外给公众一个较即时的数字。马来西亚若同时公布每小时 PM2.5，家长就能更快做判断。
  • 学校规则是否纳入瓜拉雪兰莪站，会改变部分日子的结果。附近传感器的数据累积后，可为这个问题提供依据。

附录 A　PM2.5 换算成分指数的公式

每个分指数都用同一种“分段直线”公式。先找出浓度落在哪一段，再按比例换算：

SI = (Ihigh − Ilow) ÷ (Chigh − Clow) × (C − Clow) + Ilow

  • C：PM2.5 的 24 小时平均浓度（微克/立方米）
  • C_low、C_high：该段的浓度下限和上限
  • I_low、I_high：该段对应的指数下限和上限

环境局先后发布了两份官方文件：2021 年 9 月版本放在环境局网站，2025 年 1 月版本放在 APIMS 网站。两者的 PM2.5 分段不一样[1, 2]，分歧在 API 100 至 200 之间，正好是烟霾时最常见的范围：

表 7　两份环境局 PM2.5 换算表的分段（微克/立方米）

API 分段 2025 年 1 月版本（微克/立方米） 2021 年 9 月版本（微克/立方米）
0–50 0–12.0 0–12.0
51–100 12.1–50.4 12.1–75.5
101–150 50.5–55.4 75.5–150.4（101–200 为一段）
151–200 55.5–150.4 同上
201–300 150.5–250.4 150.5–250.4
301–400 250.5–350.4 250.5–350.4
401–500 350.5–500.4 350.5–500.4

斜率表示 PM2.5 每增加 1 微克/立方米，API 增加多少点。2025 年 1 月版本在 API 101–150 最陡（斜率 10），在 151–200 最平（斜率 0.52）；2021 年 9 月版本在 100 以上只有一段，斜率 1.32。

例子：PM2.5 的 24 小时平均是 100 微克/立方米。

  • 按 2025 年 1 月版本：SI = 49 ÷ 94.9 × (100 − 55.5) + 151 ≈ 174
  • 按 2021 年 9 月版本：SI = 99 ÷ 74.9 × (100 − 75.5) + 101 ≈ 133

同一个浓度，相差约 40 点。

附录 B　名词解释

  • PM2.5： 直径 2.5 微米或以下的悬浮微粒，能深入肺部。烟霾的主要成分。
  • 分指数： 一种污染物的平均浓度换算出来的指数。
  • 滚动平均： 每小时重新计算一次，总是取最近 24 个小时。
  • NowCast： 美国用的“现在”估计值，对最近几小时给更大的比重。
  • 滞后： 指数的变化比实际空气的变化来得晚。
