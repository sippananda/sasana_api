How these numbers are worked out
  • aqicn reports the sensor as a US AQI number (US EPA 2016 scale). It is turned back into PM2.5 in µg/m³.
  • The PM2.5 values of the last 3, 6 or 24 hours are averaged. A 3-hour average needs all 3 hours, a 6-hour average at least 5 hours, a 24-hour average at least 18 hours.
  • The average is turned into an API number with the DOE table of 14 October 2026 (the one on the APIMS website).
  • Above API 150 the two scales use the same PM2.5 bands, so there the hourly value is the same number on both scales.
  • The sensor is not calibrated. Low-cost sensors can read high in very humid air. Until the comparison below has about two weeks of data, treat these numbers as a rough guide only.

7How to read this page

  • Sensor: “Jalan Anggun 3P”, a GAIA low-cost sensor in Rawang Anggun, a few kilometres from the school. Data from the World Air Quality Index project, aqicn.org.
  • Different scales. The sensor gives a US AQI. DOE gives the Malaysian API. The same air gives different numbers on the two scales. So the slope and the ratio only describe this pair. The correlation r does not depend on the scale.
  • Different averaging. The DOE API for PM2.5 uses a 24-hour mean. The sensor reading is nearly instant. So this page also builds a 24-hour mean of the sensor. A mean needs at least 18 of the 24 hours.
  • r runs from −1 to 1. Above 0.9 is a close match. Below 0.7 is a weak match.
  • DOE average: the mean of Batu Muda, Petaling Jaya, Shah Alam and Kuala Selangor, only in hours with all four readings. This is the average of the rule.
  • Cheras is collected for this page only, from 17 Oct 2026. It is not part of the rule.
  • Some sensor hours come from the aqicn map search (“map” in the data file). Those hours have the overall index only, which is the PM2.5 index for this sensor.
  • The sensor is not checked by DOE. Low-cost sensors can read high in very humid air.
